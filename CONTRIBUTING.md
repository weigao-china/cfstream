## English

Thank you for contributing to `cfstream`! Here is a simple guide to help you get started.

### 🛠️ How to Submit a PR
1. **Fork** the repository to your account.
2. **Create a branch** for your feature or bugfix:
```bash
   git checkout -b feat/your-feature-name
```

3. **Commit your changes** with a clear message:
```bash
git commit -m "feat: add xxx"  # or "fix: resolve xxx"

```


4. **Push to your fork**:
```bash
git push origin feat/your-feature-name

```


5. **Open a Pull Request** and describe what you changed.

### 🐛 Reporting Issues

* Search existing [Issues](https://www.google.com/search?q=https://github.com/weigao-china/cfstream/issues) before opening a new one.
* Provide clear context and reproduction steps when submitting an issue.

### 📜 Code of Conduct

Please follow our [Code of Conduct](https://www.google.com/search?q=CODE_OF_CONDUCT.md) to keep the community respectful and welcoming.

## 中文

感谢参与 `cfstream` 的贡献！以下是简要的贡献指南：

### 🛠️ 提交 PR 流程

1. **Fork** 本仓库到个人账号。
2. **创建分支**（请勿直接修改主分支）：
```bash
git checkout -b feat/你的功能名称

```


3. **提交代码**（使用清晰的 commit 描述）：
```bash
git commit -m "feat: 新增 xxx 功能"  # 或 "fix: 修复 xxx 问题"

```


4. **推送到你的分支**：
```bash
git push origin feat/你的功能名称

```


5. **提交 Pull Request** 并简要说明你的修改。

### 🐛 反馈问题 (Issues)

* 提交前请先搜索已有的 [Issues](https://www.google.com/search?q=https://github.com/weigao-china/cfstream/issues)。
* 创建新 Issue 时，请提供清晰的背景描述与复现步骤。

### 📜 行为准则

请遵守本项目的 [行为准则](https://www.google.com/search?q=CODE_OF_CONDUCT.md)，共同维护友好、包容的社区环境。
